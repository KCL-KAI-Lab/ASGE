# ASGE
Adaptive Spatial Goodness Encoding: Global Backpropagation-free Training Algorithm

## Necessary Packages
```
Python 3.9
torch 2.6.0+cu126
torchvision 0.21.0+cu126
```

## Implementation
Choose model from `VGG8` and `VGG11`  
Load diffrent dataset from `Load_Dataset`  
Evaluation on validation dataset is performed every epoch.
